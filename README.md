# ClosetIQ

AI Powered Fashion Recommendation Web App

## Features
- Smart Outfit Recommendation
- Weather Based Suggestions
- AI Outfit Generator
- Wishlist System
- Cart System
- Razorpay Payment Gateway
- Responsive UI
- React + FastAPI Backend

## Tech Stack
Frontend:
- React.js
- CSS
- Axios
- Framer Motion

Backend:
- FastAPI
- Pandas
- Razorpay API

## Folder Structure

src/
components/
pages/

backend/
backend.py
ecommerce_products.csv

## Run Project

Frontend:
npm start

Backend:
uvicorn backend:app --reload
